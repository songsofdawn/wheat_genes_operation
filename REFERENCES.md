# References / 参考文献

The following publications should be cited when WheatGeneToolkit data or the
corresponding analysis modules are used in research. In addition to these publications,
report the database release/version and access date whenever possible.

使用 WheatGeneToolkit 数据或相应分析模块发表研究成果时，建议引用下列文献；同时应尽可能
报告数据库版本、数据发布日期及访问日期。

## Suggested acknowledgement / 推荐致谢文字

> Wheat genomic and annotation resources used by WheatGeneToolkit were obtained from
> IWGSC RefSeq v1.1, the Fielder reference assembly, Triticeae-GeneTribe, WheatOmics,
> JASPAR, Ensembl Plants BioMart, the Gene Ontology Consortium and KEGG/BlastKOALA.
> The corresponding database releases and publications are cited in the project
> documentation.

> WheatGeneToolkit 使用的基因组及注释资源来自 IWGSC RefSeq v1.1、Fielder 参考基因组、
> Triticeae-GeneTribe、WheatOmics、JASPAR、Ensembl Plants BioMart、Gene Ontology
> Consortium 以及 KEGG/BlastKOALA；相应数据库版本及文献见项目说明。
